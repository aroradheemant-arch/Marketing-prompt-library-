# P05 — Paid Ad A/B Testing

## Workflow
Content Production

## Problem Solved
Manual variant-writing limits test volume and slows launches.

## Prompt
> Write 5 headline (≤30 chars) + description (≤90 chars) variants for [platform] ad promoting [offer] to [audience], testing [angle].

## Automation Potential
High — more variants can be tested without extra headcount.

## Risks & Limitations
- Risk of generic copy.
- Claims need legal/platform-policy checks.

## Version History
### v1.0
Initial tested version.

### v1.1
Added character limits and a testing angle.

## Iteration Rationale
The changes addressed platform-policy rejections and made the outputs more suitable for A/B testing.
